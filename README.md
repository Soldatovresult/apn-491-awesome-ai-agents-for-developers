# 🤖 Awesome AI Agents for Developers

A comprehensive, curated list of AI agents, frameworks, tools, and specialized agent skills to supercharge developer productivity in 2026.

---

## 🚀 Top Frameworks & Platforms
- **[CrewAI](https://github.com/joaomdmoura/crewAI)** - Collaborative AI agents for complex tasks.
- **[AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)** - An experimental open-source attempt to make GPT-4 fully autonomous.
- **[Microsoft AutoGen](https://github.com/microsoft/autogen)** - A framework that enables the development of LLM applications using multiple agents.
- **[LangChain Agents](https://python.langchain.com/docs/modules/agents/)** - Build agents that use LLMs to determine which actions to take.

## 🛠 Developer Productivity Agents
- **[Cursor](https://cursor.sh/)** - The AI-native code editor.
- **[Continue](https://github.com/continuedev/continue)** - The open-source AI code assistant.
- **[OpenDevin](https://github.com/OpenDevin/OpenDevin)** - An autonomous AI software engineer.
- **[Manus AI](https://manus.im)** - A general-purpose autonomous AI agent for end-to-end task execution.

## 💡 Specialized Agent Skills
Agent skills are modular, self-contained packages that extend an agent's capabilities.
- **[Agent Payment Node](https://github.com/nuanu-ai/agent-payment-node)** - Local payment runtime and stdio MCP tools for x402 offers, bounded payment preparation, status and receipts; Apple Silicon macOS and Node 24 only.
- **[Autonomous Manager](https://github.com/sahprem304-tech)** - A skill for fully autonomous project management and background execution.
- **[Credit Optimizer](https://github.com/sahprem304-tech)** - Automatically route tasks to the most cost-efficient execution path.
- **[Automation & Scheduling](https://github.com/sahprem304-tech)** - A framework for recurring and event-triggered agent execution.
